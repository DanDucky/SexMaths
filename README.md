# SexMaths (/ˈsɛx.mæθs/)

$$
\text{TexMaths} \mapsto \text{SexMaths}
$$

Allows you to use Tectonic in TexMaths. Pretty egregiously hacky solution to a hacky plugin. I had to read StarBasic for this!!!! KNEEL BEFORE ME I AM ~A~ GOD. This will highkey lowkey midkey break anytime anything updates... so Be Warned.

## Installation

Put this somewhere safe, then open the TexMaths config and set the LaTeX link to `tectonic.sh` and the dvipng and dvisvgm links to `dvisvgm.sh`.
